# utilities

Personal productivity tools and VS Code extensions.

## Tools

| Tool | Description | Version |
|---|---|---|
| [vscode-markdown-toggle](./vscode-markdown-toggle/) | VS Code status bar toggle for Markdown preview with optional forced light theme | 1.2.4 |
| [rocketscanner-breach-monitor](./rocketscanner-breach-monitor/) | Monitors public breach feeds (HIBP, ransomware.live, RSS) and alerts when a watchlisted vendor appears | 0.1.0 |

## Structure

Each tool lives in its own subdirectory with its own `README.md`, `package.json`, and `CHANGELOG.md`.
