# utilities

Personal productivity tools and VS Code extensions.

## Tools

| Tool | Description | Version |
|---|---|---|
| [vscode-markdown-toggle](./vscode-markdown-toggle/) | VS Code status bar toggle for Markdown preview with optional forced light theme | 1.2.4 |
| [claude-iterm-recover](./claude-iterm-recover/) | iTerm2 profiles that launch Claude Code with Remote Control, and a tool that brings sessions back after a reboot or crash | 1.0.0 |

## Structure

Each tool lives in its own subdirectory with its own `README.md` and `CHANGELOG.md` (VS Code extensions also carry a `package.json`).
